## System overview

See [system-overview.mmd](system-overview.mmd) for the full-system diagram.

This repo is a Claude Code plugin marketplace for enterprise fintech/banking
guardrails, plus generated ports of the same content to Codex, Cursor, and
Copilot CLI. There is no application code: the deliverables are plugin
manifests (JSON), agents/skills/commands (Markdown), and bash/PowerShell
enforcement hook scripts, with a build script that fans canonical content out
to every target. Alongside the marketplace live three Copilot-CLI support
systems: an OTEL hook-event bridge, an MCP wrapper around the Copilot CLI,
and a small agent-liveness MCP toolkit.
